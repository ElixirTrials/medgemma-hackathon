# Sample Data for Criteria Extraction Demo

Place sample clinical trial protocol PDFs in this directory to use with the demo notebook.

## Requirements

- PDF files containing clinical trial protocols with eligibility criteria sections
- Files should be named descriptively (e.g., `NCT12345678_protocol.pdf`)

## Where to find sample protocols

1. **ClinicalTrials.gov** — Search for trials and download protocol PDFs
2. **FDA Drug Trial Snapshots** — Public protocol documents
3. **PubMed Central** — Open-access clinical trial protocols

## Usage

The notebook will look for PDF files in this directory. Place at least one PDF here before running.
